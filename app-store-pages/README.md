# A1打卡 App Store 页面

这个目录用于发布 App Store Connect 需要的公开网页：

- `support.html`：技术支持 URL
- `privacy.html`：隐私政策 URL

推荐发布到 GitHub Pages。仓库名可用：

```text
a1-checkin-support
```

发布后在 App Store Connect 填：

```text
技术支持 URL：https://a1studio-user.github.io/a1-checkin-support/support.html
隐私政策 URL：https://a1studio-user.github.io/a1-checkin-support/privacy.html
```
